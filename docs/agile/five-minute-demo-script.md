# Sprint 0 five-minute demo script

Use synthetic data and a clean checkout. Do not use real accounts or private
media.

1. **Board and goal — 20 seconds.** Show the Sprint 0 Project, its workflow,
   two-story In Progress limit, and the walking-skeleton goal.
2. **Clean start — 40 seconds.** From the documented path, run `npm ci`,
   `npm run check`, then `npm run web`; open the local URL.
3. **Honest shell — 20 seconds.** Show the Rewind title and `Local demo`
   disclosure. Explain that the current screen is a foundation shell, not a
   login or finished feature.
4. **Quality evidence — 60 seconds.** Show the focused test and the CI run;
   explain the accessible heading and status label.
5. **Architecture and scope — 60 seconds.** Show the local-first ADR, glossary,
   and contracts; point out the membership-denial and locked-media boundaries.
6. **What comes next — 40 seconds.** Show the backlog items for navigation,
   profile selection, group capsule, and later camera work. Explicitly call out
   that no cloud, recording, chat, reveal, or archive media is being claimed.

Leave the remaining time for reviewer questions and capture feedback as a
backlog item or decision; do not silently expand the sprint commitment.
