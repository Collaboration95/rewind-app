L1The product

A real-account group collects photos and short videos during a cycle. Contributions stay sealed until release. The server builds a film for the premiere, retains published films in Archive, and supports group chat and web-push reminders. Members can save released films and their own released clips.

The synthetic Demo was removed on 6 October 2026. The tag demo-frozen-20261004 preserves history. Hosted-dev resource names still contain demo; that name does not indicate a Demo product mode. iPhone delivery is the installed PWA; compiled native iOS is out of scope.

L2The deployment boundaries

The default deployment is one Node application process beside nginx. PostgreSQL and S3 are external services. Locally, SQLite and disk media replace those stores. Cognito handles web/PWA sign-in, then the server issues its own opaque cookie session. Developer password sign-in remains on local/dev; release rejects it.

The diagram describes hosted architecture. At this source revision, dev PostgreSQL cutover is enabled; release database cutover is disabled in Terraform. Release operational completion remains in #230, #504 and #515. No cloud check was performed for this guide.

L3Life of one contribution

S3 upload intents bind incoming bytes, checksum, scope and expiry. Disk intake sends bytes through Node. Direct S3 upload avoids that intake hop, but Node still verifies/materializes objects for ffmpeg, stores processed outputs and serves authorized reads. Publication and member policy control access; possessing a group ID or S3 object reference does not grant it.

L5Delivery and verification

Focused branches target dev, with an up-to-date aggregate Quality check. Batch work includes one review-agent pass. Sensitive changes leave merge to the owner. Merges to dev deploy automatically through the configured workflow; release promotion to main follows its protected PR path. A workflow declaration alone does not establish a successful deployment.

Use the cheapest environment that exercises a change. Local account flows use make run-real at http://localhost:8090 with ten-minute cycles; make run currently aliases it. Hosted HTTPS checks cover provider/storage/platform integration. Browser notification acceptance is different from visible receipt on an installed iPhone PWA.

Decision index and limits

  • ADR-0001 records the historical local-first boundary. Its offline fixture fallback is superseded.
  • ADR-0003 explains PostgreSQL while preserving synchronous persistence calls and serialized writers. Local SQLite stays.
  • Cognito decisions explain PKCE, opaque app sessions and environment isolation.
  • The active media Terraform root uses SSE-S3 (AES256). KMS is supported by another module/adapter configuration; it is not the current root's setting.
  • SSE delivery, capability grants and some caches are process-local. Durable jobs do not make API replicas share those maps.
  • Reminders use web push only. Expo/native push code remains disabled.
