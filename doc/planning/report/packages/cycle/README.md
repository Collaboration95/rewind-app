**Evidence cut:** accepted `dev` commit [`fc2b8c811e9c13b176113fa0bdb2c015798990b4`](https://github.com/Collaboration95/rewind-app/commit/fc2b8c811e9c13b176113fa0bdb2c015798990b4), refreshed 3 October 2026. It follows [Issue #359](https://github.com/Collaboration95/rewind-app/issues/359), [the submitted proposal](../../../proposals/proposal-rewind.md) §§3.2, 5.1–5.3, 7.2 and 8, and the course evidence requirements in the [project brief](../../../context/project-brief.md). The issue supplies the report-model acceptance contract for one analysis/design class view per use case, a sequence per major flow, and before/after class and sequence views for the design problem. The package reuses [the cycle domain contract](../../../../../docs/domain/cycle-control-contract.md), [domain contracts](../../../../../docs/domain/contracts.md), and [the persistence architecture note](../../../../../docs/architecture/hosted-demo-persistence.md). Links to implementation are pinned to the evidence-cut commit.

## Evidence and limits

- All code citations use the immutable accepted source cut `fc2b8c811e9c13b176113fa0bdb2c015798990b4`; local line numbers are attached to each GitHub link.
- Analysis diagrams show actors and domain concepts. Design diagrams show only functions, persisted records, adapters, and types that exist in the pinned source. They do not add a class hierarchy for a textbook pattern.
- The local Demo cycle-control endpoint is distinct from the automatic real-group scheduler. The diagrams do not treat a Demo advance button or deterministic test clock as hosted scheduling evidence.
- The current runtime is the local SQLite-backed application boundary shown by `docs/architecture/hosted-demo-persistence.md`. Managed OIDC, PostgreSQL, managed backup, and pre-upload retro treatment are future Sprint 3 work.
- No product tests were run for this prose/model-only package. All package SVGs are rendered to PNG with the existing local ImageMagick SVG renderer and visually inspected at presentation scale; no diagram dependency is added.
