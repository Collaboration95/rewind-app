## Evidence boundary

- UC12 covers current premiere state, released archive browsing and protected playback. UC13 covers member-owned processed clips and group films downloads. UC14 covers web/PWA install/update and invitation links opened by browser or native scheme.
- The implemented demo uses a local/hosted runtime and SQLite with a configured media store. `server/src/archive/store-serving.ts` materializes and verifies stored bytes; it does not establish that an S3 object store is the deployed backing provider. S3 delivery remains unverified.
- The client uses `expo-video` and browser/native download branches. Source and fixtures establish the code paths, not audible playback on an installed physical phone, browser/device universal-link association, or provider-specific behavior. Those remain open validation boundaries.
- `app.json` disables Expo native updates. The service-worker install/update behavior documented here applies to the web/PWA shell only.
- The report-template and issue acceptance contract require analysis/design class models, per-major-flow sequence pairs, pattern comparison, source traceability and readable rendered figures. Every described exception appears in its flow text and paired figure.

## Design choices evidenced at this cut

- **Proxy:** the protected-media route and `MediaCapabilities` mediate access to stored media. Grants are short lived and purpose bound; resolution checks the current session, selected group membership, release state and verified output before serving.
- **Adapter:** `downloadReleasedArchiveMedia` chooses browser fetch/anchor or Expo filesystem delivery. The deep-link module also normalizes supported browser and `rewind://invite` shapes. These are concrete platform boundaries, not proposed classes.
- **Facade:** `createRealAccountArchiveClient` groups premiere/archive requests and maps server response shapes into client domain values.
- The before figures are conceptual alternatives, not historical code. The after figures name actual modules and behavior. The package proposes no production refactor to manufacture patterns.
