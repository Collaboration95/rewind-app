## Rebuild and integration

The maintained source is [build-presentation.mjs](build-presentation.mjs). It uses only the bundled JavaScript Artifact Tool for PPTX authoring. Set REWIND_REPORT_SOURCE_DIR to the lead report folder containing report-draft.md and diagrams, and REWIND_BUILD_DIR to a new private temporary directory. Execute with the bundled Node runtime. Follow the Presentations skill's authoring-start marker before an authoring run. The builder finalizes to its private final directory and renders all final slides there. After visual inspection, copy that finalized PPTX unchanged to ../exports/rewind-project-demo-draft.pptx. Temporary renders, candidate decks and validation receipts do not belong in the report output paths.

No product test or fixture is executed by this builder. The accepted local fixture results cited in the slides come from #396 evidence, not from this documentation assignment. The final PDF is optional and is not part of this bounded draft. Lead integration must preserve the source notes and the open factual, hardware, hosted, provider and Sprint 3 compliance gates.
